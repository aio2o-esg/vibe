# SPEC: 온라인 천문대

## 프로젝트 이름
온라인 천문대 (space)

## 목적
말없이 같이 별을 보며 쉬는 웹 공간.

## 이번 범위
- 오름 위 밤 천문대 3D 화면(오름, 망원경, 늦가을 밤하늘)
- 내 캐릭터 걷기(클릭, WASD, 방향키, 휴대폰 터치)
- 별 10개를 눌러 별자리 잇기 행동 1개
- 소리(풀벌레 소리)
- 같은 링크로 들어온 사람끼리 보이기

## 제외 범위
- 채팅
- 로그인
- 결제
- 개인정보 수집
- 외부 이미지와 3D 모델 파일

## 완료 기준
- R1. 둥근 오름 꼭대기, 그 위에 선 망원경 1대(VESPERA II처럼 흰 둥근 몸통 옆에 경통이 붙은 스마트 망원경, 몸통에 "VESPERA II" 글씨), 별이 가득한 밤하늘이 보인다. 내 인형(눈사람) 아랫부분 등쪽에는 옷 무늬처럼 "MARUSYS edu" 글씨(MARUS·S는 검정, Y·edu는 하늘색)가 있다. (브라우저로 space/index.html을 열어 네 가지가 모두 보이는지 본다)
- R2. 땅을 클릭하거나 WASD, 방향키를 누르거나 휴대폰 화면을 누르면 내 인형이 오름 비탈을 따라 그쪽으로 천천히(1초에 2칸) 걷고, 카메라가 인형 뒤에서 따라간다. 한 번 누르면 그 방향으로 최대 8칸까지만 걷는다. (클릭, 키 입력, 휴대폰 터치를 각각 해 보고 인형이 천천히 움직이며 화면 안에 계속 보이는지, 멀리 하늘을 눌러도 조금만 가는지 본다)
- R3. 밤하늘에 실제 별(6등급까지 약 5,000개)과 88개 별자리가 실제 위치에 놓여, 11월 하순 밤 9시 제주(북위 33.4도)에서 본 하늘과 같다. 밝은 별일수록 크고, 은하수도 실제 자리에 있다. 카시오페이아는 북쪽 높이, 가을 대사각형(페가수스)은 남쪽 하늘 높이, 플레이아데스는 동쪽에 있다. (같은 날짜·시각·장소로 맞춘 별자리 앱 화면과 나란히 놓고 카시오페이아·페가수스·오리온의 방향과 모양이 같은지 본다)
- R4. 망원경 가까이에서 망원경 보기 버튼을 누르면 둥근 접안렌즈 화면으로 바뀐다. 끌거나 방향키로 하늘을 둘러보고, +/− 버튼이나 휠로 확대할수록 별이 더 밝고 또렷해져 6등급 별까지 잘 보인다. 이 화면에서는 땅을 숨겨 지평선 아래까지 온 하늘(88개 별자리 모두)을 둘러볼 수 있고, 지평선은 옅은 선으로 보인다. 별자리 선은 이 화면에서만 은은하게 보인다. 같은 버튼으로 걷는 화면으로 돌아온다. (망원경 옆에서 버튼을 누르고, 끌기·방향키·확대를 해 본 뒤 다시 눌러 돌아오는지 본다)
- R5. 별자리 잇기 버튼을 누른 뒤 하늘의 별 10개를 차례로 누르면 금색 선으로 이어지고, 10초 뒤 사라진다. (버튼을 누르고 별 10개를 눌러 선이 생기는지, 초시계로 10초 뒤 사라지는지 본다)
- R6. 오늘 만든 별자리 수가 화면 위에 보이고, 다시 열어도 남는다. (별자리를 2개 만들고 새로고침해 숫자가 같은지 본다)
- R7. 소리 켜기 버튼을 눌러야 소리가 시작되고, 같은 버튼으로 끈다. (처음 열었을 때 무음인지, 버튼 두 번 누르면 켜졌다 꺼지는지 본다)
- R8. 소리를 켜면 풀벌레 우는 소리와 밤바람 소리가 외부 소리 파일 없이 Web Audio로 만들어져 나고, 1분 넘게 들어도 끊기지 않는다. 소리가 켜져 있을 때 별자리가 완성되면 맑은 종소리가 한 번 울린다. (소리를 켜고 1분 동안 들어 보고, 별자리를 하나 만들어 종소리가 한 번만 나는지 본다)
- R9. 같은 링크를 연 다른 창의 사람이 색이 다른 인형으로 그 위치에 보인다. (브라우저 두 창을 열어 한 창에서 걸으면 다른 창에서 움직이는지 본다)
- R10. 다른 사람이 나가면 인형이 지워지고, 화면 위 사람 수가 맞게 바뀐다. (두 창 중 하나를 닫고 사람 수와 인형을 본다)
- R11. 다른 사람이 별자리를 만들면 내 화면의 하늘이 잠깐 반짝인다. (두 창에서 한쪽이 별자리를 만들고 다른 창을 본다)
- R12. 이름, 채팅, 개인정보를 보내지 않고, 외부 이미지와 모델 파일 없이 코드로만 그린다. (코드에서 send하는 내용이 위치와 별자리 완성 신호뿐인지, 네트워크 탭에 이미지 요청이 없는지 본다)

- R13. 망원경 화면에서 별자리를 누르면 그 별자리 선이 밝아지고 한글 이름(예: 카시오페이아자리)이 3초 동안 별자리 옆에 뜬다. (카시오페이아·페가수스·고니를 눌러 이름이 맞는지 본다)

## 수동 확인
- 브라우저 두 창과 휴대폰으로 R1~R13을 위 방법대로 확인한다.
- 자동 테스트는 없다.

## 남은 위험
- 연결 중개 서버(공개 신호 서버)가 느리거나 막히면 다른 사람이 보이지 않을 수 있다.
- 회사나 학교 네트워크의 방화벽에서는 휴대폰과 PC가 서로 못 볼 수 있다.
- 소리는 브라우저 정책 때문에 첫 터치 뒤에만 난다.
